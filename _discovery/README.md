# _discovery

Esta pasta é a saída da curadoria do Discover: o material que
alguém trouxe, lido por agentes e transformado em assets que se
versionam.

**Ela é gerada.** O agentic-squad reescreve o que ele mesmo
escreveu. O que você editar à mão ele não sobrescreve: o `hash`
do frontmatter deixa de bater, e a mudança passa a chegar como
diff, para você decidir.

Arquivo daqui sem frontmatter de geração é tratado como seu.
